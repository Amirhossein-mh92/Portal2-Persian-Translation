# Portal 2 - Persian (Finglish) Translation

Persian (Finglish) subtitle translation for Portal 2. Translates all character dialogue (GLaDOS, Wheatley, Cave Johnson) and environmental captions into readable Finglish text. Compatible with both Single Player and Co-op.

## Features

- All character dialogue translated to Finglish
- Environmental captions translated
- System announcements translated
- Turret dialogue translated
- Developer Commentary translated
- Compatible with Single Player and Co-op

## Installation

1. Download the latest release from the [Releases page](https://github.com/Amirhossein-mh92/Portal2-Persian-Translation/releases)
2. Extract the zip file
3. Run `install.bat`
4. If the game folder is not found automatically, enter the path manually
   (Example: `D:\SteamLibrary\steamapps\common\Portal 2`)
5. Launch the game and enjoy!

## Uninstallation

1. Run `uninstall.bat`
2. If the game folder is not found automatically, enter the path manually
3. The original English files will be restored
